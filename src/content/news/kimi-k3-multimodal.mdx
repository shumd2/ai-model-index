## Kimi K3 Multimodal brings 2.8T parameters and vision at $3/M input

Moonshot AI released Kimi K3 Multimodal, the largest variant of the K3 family with 2.8 trillion total parameters and native multimodal input support. At $3 per million input tokens and $15 per million output tokens, it delivers frontier-level multimodal reasoning at a competitive price point.

### Benchmark performance

- **AA Intelligence Index:** 59.7
- **AA-Briefcase:** 1548 Elo (rank #2)
- **Context window:** 1,048,576 tokens
- **Architecture:** Mixture-of-Experts with efficient activation

### Why it matters

The original K3 was text-only and already impressive. Adding multimodal input — images, documents, charts — at the same intelligence level makes this model practical for real-world enterprise workflows where data arrives in multiple formats. The 2.8T parameter MoE architecture provides strong reasoning capability while maintaining reasonable inference costs.

K3 is available through Moonshot's official API and select third-party providers.
