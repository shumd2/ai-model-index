Z.ai — the lab behind the GLM line — **open-sourced ZCode** on September 22 after a researcher disclosed that the client had been silently uploading full user workspaces, including Git history, credentials and cloud keys, to Alibaba Cloud storage.

The company apologized, removed the Repo Wiki and commissioned audits by CAICT and NSFOCUS. An enterprise customer filed a legal demand on September 19. The open-sourcing follows the disclosure rather than preceding it — the code is now public, and the audit results should be too.

For developers, the lesson generalizes: agentic coding tools with broad filesystem access are data-exfiltration surfaces by default. Vendor audits, egress controls and the license all matter when the tool reads your whole repo.
