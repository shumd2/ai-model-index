The **Claude Developer Platform announced on September 30** the deprecation of **Claude Sonnet 4.5** (`claude-sonnet-4-5-20250929`), with retirement scheduled for **November 30, 2026**.

This is the first 4.x Sonnet retirement in the 5.5 wave. The migration path is **Sonnet 5.5** (released Sep 28), which Anthropic positions as "a faster, lower-cost complement to Opus 5.5" at the same $2/$10 list price.

Developers using the snapshot ID `claude-sonnet-4-5-20250929` should migrate before the November 30 cutoff.
