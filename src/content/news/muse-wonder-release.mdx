At 56, Full lands in the top four. Three models sit at that score — Sonnet 5.5 (max), Opus 5.5 (xhigh) and Full — and only Opus 5.5 at max clears it, at 58. Artificial Analysis lists Full as having **no publicly available API**.

Muse Wonder (max) scores **52**, at $4.52 per task and 131 output tokens per second.

One note on price: at $4 input / $20 output, Muse Wonder costs **exactly what Claude Opus 5.5 costs**. Meta Superintelligence Labs chief Alexandr Wang had said Wonder would be priced "meaningfully below" OpenAI and Anthropic. On the API, that turned out not to be the case.

## Active Memory and Active Focus

These are the headline capabilities, and neither is a benchmark result:

- **Active Memory** carries context across separate conversations, so an agent does not rebuild its understanding every time you return to it
- **Active Focus** keeps the agent working through its own errors rather than abandoning the task, and has it check in before taking actions with real consequences

Meta frames the line around personal and professional agentic work, naming law, finance and health as particular strengths, alongside "frontier coding performance".

## The API problem

**Muse Wonder Full has no API model ID.** Meta's own model documentation states it is unavailable on the Meta Model API in either Standard or Contributor mode. There is no per-token purchase at any volume — your only route is a Muse Code subscription, and only the two priciest plans.

Muse Wonder itself is `muse-wonder-1.0` at `https://api.meta.ai/v1`:

| | USD per 1M tokens |
|---|---|
| Input | $4.00 |
| Cached input | $0.20 |
| Output | $20.00 |

1,048,576-token context with **no long-context premium**, reasoning effort from `minimal` to `max`, text/image/video/audio/PDF input, and preview status. Web-search grounding is $2.50 per 1,000 queries; rate limits are 3,000 RPM and 4M TPM.

Note that Contributor mode — which prices Muse Spark 1.3 at $0.10/$0.20 instead of $1.25/$4.25, a cut of more than 12× — is **not offered for Wonder on the Model API**.
