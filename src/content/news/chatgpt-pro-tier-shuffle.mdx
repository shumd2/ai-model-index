OpenAI restructured ChatGPT Pro into usage-based tiers, then **paused new sign-ups and upgrades to the $200 Pro 20× plan on September 10, 2026**.

What changed:

- **Pro $100 (5×)** — new tier with 5× the Codex usage of Plus, aimed at long, high-effort sessions
- **Pro $200 (20×)** — remains the highest usage tier, but new sign-ups and upgrades are paused; existing subscriptions renew as usual, and eligible customers get a one-time 30-day return window after their access ends
- **Pro $500** — announced at DevDay (Sep 30) with GPT-6 Astra Ultrafast access (Ultrafast burns included usage at 8× the standard rate)

Both Pro tiers include the same core capabilities: Pro models, Codex, deep research, image creation, memory and file uploads. The difference is the usage allowance.

For the index: if you were planning to subscribe at the top tier, the $100 Pro 5× is the only option for new subscribers — budget accordingly, and check the usage dashboard before committing to a Pro tier.
