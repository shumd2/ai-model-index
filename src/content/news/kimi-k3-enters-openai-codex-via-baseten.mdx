**Moonshot AI's Kimi K3** is now available to **OpenAI enterprise customers through Baseten inference**, with usage counted against existing OpenAI spending commitments — the first time a Chinese open model enters OpenAI's enterprise billing system.

Per Sina Finance (Sep 30), the arrangement lets customers use Kimi K3 within an existing procurement agreement, without adding a separate supplier contract. Baseten provides the model inference; Codex provides the developer interface.

Separately, a **Kimi K3.1 identifier reportedly surfaced in the Moonshot API registry** (TechNode, Sep 30) — an incremental update that may ship in the coming weeks. Kimi K3 (2.8T params, 1M context, open weights) remains the current flagship.
