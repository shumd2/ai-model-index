**Liner**, known for its browser extension, launched the **Liner Model API** on September 24: a model-routing API at **$1/$6 per 1M input/output tokens, with cached input at $0.10**, claiming at least 50% savings versus same-tier models.

The entry matters less for its price card than for the trend: routing APIs are becoming the default access layer, and the field now includes OpenRouter, Liner, Fireworks, Together, Groq, Cerebras, SambaNova and the cloud catalogs — each with different routing logic, latency profiles and model coverage.

We list first-party APIs, routers, cloud catalogs and self-hosted infrastructure separately in the API access directory, because "who serves the model" changes your data-handling, SLA and portability — even when the model ID looks the same.
