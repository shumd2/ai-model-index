OpenAI rolled out **GPT-6 across ChatGPT** on October 7, reaching the full base of more than **1.2 billion weekly ChatGPT users**.

**Which model runs where:**

| Tiers | Model |
|---|---|
| Plus, Pro, Business, Enterprise | **GPT-6 Sol** |
| Free, Go (from Oct 8) | **GPT-6 Luna** |

Both are tuned for everyday conversation. The models powering Work and Codex are unchanged by this release.

## Intelligent UI

The headline feature is a new response format. GPT-6 was trained to compose answers from text, visuals and interactive elements — graphics, tappable buttons, forms, charts — choosing the mix that fits the question.

Underneath is a library of native streamable components plus a compiler that renders the interface progressively as the model generates it, rather than waiting for the full response. A comparison might come back side by side; an explanation might render as an interactive diagram; a simple question still gets plain text.

## Interleaved thinking

ChatGPT can now begin answering while the model is still thinking. OpenAI says GPT-6 Extra High starts replying in the same time as GPT-5.6 Medium while scoring better than GPT-5.6 Extra High, and that GPT-6 Instant answers web-search questions **44% sooner** than GPT-5.6 Instant.

The model was trained to compose across multiple partial responses, adding information without filler while keeping the whole answer coherent.

## Why it matters for model selection

This is a product release, not an API release — **no new API model IDs, pricing or context windows were published**. The practical effect for the index is that the GPT-6 family is now what most people actually experience, while developers on the API remain on the September GPT-6 Sol and Luna.
