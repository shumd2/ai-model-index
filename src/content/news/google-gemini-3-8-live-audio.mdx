## Google releases Gemini 3.8 Live audio models with voice-agent capabilities

Google DeepMind launched two Gemini 3.8 Live audio models on September 15, 2026, supporting voice agents that process visual input and make API calls simultaneously across more than 97 languages.

### Key features

- **Visual input processing:** Agents can see and reason about visual context during voice conversations
- **API call integration:** Agents can make external tool calls mid-conversation
- **97+ languages:** Broad multilingual support
- **Extended Thinking variant:** Ranks first on the AA Speech-to-Speech Leaderboard at 82.6%

### Pricing

Extended Thinking variant: $0.005 per minute of audio input and $0.018 per minute of output — roughly $1.38/hour. This is competitive with OpenAI's GPT-Live-1, which ships at $3+/hour.

The Gemini 3.8 Live models are available through the Gemini API and AI Studio.

Source: Google DeepMind announcement, September 15, 2026
