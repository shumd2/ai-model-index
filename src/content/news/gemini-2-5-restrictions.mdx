Google restricted its **Gemini 2.5 family** in stages: Gemini 2.5 Pro disappeared from AI Studio on September 18, and Google confirmed access is now limited to existing users — "not deprecated," with the API still serving. Meanwhile Google Cloud lists **gemini-2.5-pro for retirement on October 20, 2026**, pointing to gemini-3.8-flash and gemini-3.5-flash as replacements.

The distinction matters for planning: AI Studio access and Cloud retirement are different surfaces with different dates. Existing API integrations keep working until the Cloud retirement date, but new projects should target the 3.8/3.5 generation.

The registry keeps Gemini 2.5 Pro as a legacy entry; the successor generation (3.8 Flash at $0.75/$3.75 intro pricing) is the current value pick.
