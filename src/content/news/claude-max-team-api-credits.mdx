Anthropic is bundling **monthly Claude Platform API credits** into Max and Team subscriptions, announced October 7 and rolling out over a few days.

| Plan | Monthly API credit |
|---|---|
| **Max 5×** | $100 |
| **Max 20×** | $200 |
| **Team** | Up to $500, pooled across users |

Credits work on **any model** and are designed for building agents and applications that call the Claude Platform — not for topping up chat usage. You link a Claude Console org (Max: Settings ▸ Billing; Team: Org settings ▸ Billing) to activate them.

## Why this is a real change

Chat subscriptions and Platform API have always been separate billing environments. A Max subscriber wanting to run an agent on Haiku 5.5 or Sonnet 5.5 through the API paid full API rates on top of the subscription.

At $0.10 per million input tokens, $100 of credit covers roughly a billion input tokens on Haiku 5.5. That is not a token-granularity allowance — it is a working budget for a small production agent.

## The pairing

The credits landed the same day as **Claude Haiku 5.5** and the **Sonnet 5.5 cache-read price cut**. Read together, the announcement is a push to make subscription-holders build on the Platform rather than merely chat in the app: a cheap model, cheaper cache reads on the mid-tier model, and a monthly credit that makes prototyping free.

If you were on the fence between Claude Pro and Max purely for Claude Code usage, the Max tiers now have an API allowance attached — which narrows the gap with running the API directly at pay-as-you-go rates.
