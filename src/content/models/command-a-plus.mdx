## Overview

Command A+ (May 2026) is Cohere's first Mixture-of-Experts model, and the pitch is consolidation: vision input, agentic tool use, reasoning and 23-language translation in one set of weights.

The detail that matters for enterprises: it runs on one B200 or two H100s. That's deployable without a cluster.
