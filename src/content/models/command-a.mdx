## Overview

Command A (March 2025) built Cohere's enterprise reputation: 256K context, agent- and RAG-first design, 150% more throughput than Command R+, and it only needs two GPUs.

A+ has taken the crown, but Command A still runs in a lot of Bedrock and Foundry deployments.
