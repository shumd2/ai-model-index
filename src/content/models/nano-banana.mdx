## Overview

Nano Banana is the image model inside Gemini. nano-banana-2 (Gemini 3.1 Flash Image) holds a top-10 text-to-image spot at 1261 Elo, and nano-banana-pro is a top-10 image editor at 1390.

The killer feature is context: you edit images inside the same chat where you're working, with the model understanding what's in the picture.
