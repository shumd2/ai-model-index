## Overview

Grok 4.20 is the experimental branch: a **1M-token context window** plus a **multi-agent beta** that runs parallel Grok instances on one problem.

It's explicitly beta, but the context window makes it a serious tool for codebase-scale analysis and massive document sets. xAI's own docs price it at $1.25/$2.50 under 200K prompt tokens.
