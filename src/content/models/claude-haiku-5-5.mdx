## Overview

**Claude Haiku 5.5** (`claude-haiku-5-5`) launched October 7, 2026 as Anthropic's cheapest, fastest and most capable small model. It completes the Claude 5.5 family alongside Opus 5.5 and Sonnet 5.5.

Three things changed at once versus Haiku 4.5: the **price collapsed**, the **context window grew five-fold**, and Haiku gained an **effort dial**.

## Specs at a glance

| Property | Haiku 5.5 | Haiku 4.5 |
|---|---|---|
| **Model ID** | `claude-haiku-5-5` | `claude-haiku-4-5` |
| **Context window** | 1M tokens | 200K |
| **Max output** | 128K tokens | 64K |
| **Input (≤100k prompts)** | $0.10 / MTok | $1.00 |
| **Output (≤100k prompts)** | $0.50 / MTok | $5.00 |
| **Cache read** | $0.01 / MTok | $0.10 |
| **Cache write** | $0.125 / MTok | $1.25 |
| **Effort control** | Yes (first Haiku class) | No |
| **Bedrock ID** | `anthropic.claude-haiku-5-5` | — |

Prompts **over 100k tokens** price at a higher tier: $0.50 input / $2.50 output / $0.05 cache read / $0.625 cache write.

## Where it fits

Anthropic is explicit about the boundary. Sonnet 5.5 and Opus 5.5 remain better at *complex* agentic coding (Terminal-Bench 4.0: 70.6% vs 39.2%). Haiku 5.5 is for **narrowly scoped tasks that were previously cost-prohibitive**: compaction, summarization, classification, database queries, extraction, and subagent roles inside Opus/Sonnet coding runs.

## Migration notes

- **New tokenizer** — the same text costs roughly **30% more tokens** than on Haiku 4.5, which partly offsets the per-token price cut.
- **Thinking blocks are account-bound.** Send a thinking block back after changing the system prompt, tools, or earlier messages and you get a `400`. Keep conversations append-only. Haiku 4.5 does not enforce this.
- **Adaptive thinking is on by default.** Prefer the `effort` parameter over `thinking: {"type": "disabled"}` for cost/quality trade-offs.

## Also announced Oct 7

- **Sonnet 5.5 cache reads halved** — $0.20 → $0.10 per MTok, cutting typical agentic cost by ~20%.
- **Monthly API credits for subscribers** — Max 5× gets $100/mo, Max 20× $200/mo, Team up to $500/mo pooled, usable on any model.
- **Claude Python and TypeScript SDKs** gained computer-use and browser-use support in beta.
